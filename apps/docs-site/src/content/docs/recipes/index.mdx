Every recipe shows one scenario twice: the test you write, and the documentation it generates. Pick your framework in the tab strip on any recipe and the rest of the site follows that choice.

<Aside title="One output, nine adapters">
The generated documentation is identical whichever adapter you use. Only the test code changes. Eight recipes are marked **all languages** below; the rest cover Vitest, Jest, Playwright, and Cypress.
</Aside>
